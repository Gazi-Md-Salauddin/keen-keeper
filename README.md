# KeenKeeper -  keep your Friendships

## 📝 Description
Keenkeeper is a modern interaction tracking system to monitor communication and stay connected effortlessly.

## 🛠️ Technologies Used
- React Js 
- React Router
- Javascript
- Tailwind + DaisyUI
- React Context API 
- Recharts

## 🚀 Features

- Track Calls, Text and Video
- Filter interactions by type (call, text, video)
- View interaction history in timeline
